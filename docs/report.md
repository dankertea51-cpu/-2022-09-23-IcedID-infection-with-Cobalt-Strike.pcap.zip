Цель анализа — выявить признаки компрометации: C2-серверы, каналы утечки данных и нестандартные сетевые соединения.

Объект исследования — сетевой дамп `2022-09-23-IcedID-infection-with-Cobalt-Strike.pcap`, опубликованный на образовательной площадке malware-traffic-analysis.net.

## 3. Ход анализа

### 3.1 Общая статистика

Длительность записи достоверно установить не удалось; количество пакетов и потоков не позволяет сделать точные выводы о масштабе атаки. Поэтому дальнейший анализ строился не на объёмных метриках, а на качественных признаках — составе DNS-запросов и характере соединений.

### 3.2 DNS-запросы

При изучении DNS-запросов внимание привлекли три домена.

**`trallfasterinf.com`** — выглядит как типичный фишинговый домен. Проверка в VirusTotal подтвердила это: 10 антивирусных движков, включая Sophos, Fortinet и BitDefender, классифицируют его как угрозу.

**`ctldl.windowsupdate.com`** — формально легитимный домен Microsoft, который используется для загрузки списков отзыва сертификатов. Однако его появление в дампе требует проверки: иногда такие домены используют для обхода блокировок и «растворения» вредоносного трафика в легитимном.

**`win-cosmic-mind.monasticservice.org`** — подозрителен из-за нестандартного имени и, что важнее, из-за использования порта 445.

### 3.3 Подозрительные соединения

После фильтрации трафика по IP-адресам, связанным с подозрительными доменами, обнаружено следующее.

| Соединение | Наблюдение |
|---|---|
| `137.184.114.20:80` ← домен `trallfasterinf.com` | Фишинговый ресурс, размещённый на хостинге DigitalOcean |
| `209.197.3.8:80` ← домен `ctldl.windowsupdate.com` | Принадлежит Microsoft, сам по себе подозрений не вызывает, но высокая частота запросов может указывать на маскировку |
| `10.9.23.23 → 445/TCP` → `win-cosmic-mind.monasticservice.org` | **Самое тревожное соединение в дампе** |

Порт 445 используется протоколом SMB, который обычно работает внутри сети. Исходящий SMB-трафик на внешний домен — нетипичное поведение, которое может указывать на попытку распространения вредоносного ПО (lateral movement) или на наличие бэкдора.

### 3.4 Аномалии портов

**Порт 80 (HTTP)** — используется для связи с фишинговым доменом `trallfasterinf.com`. Порт стандартный, но сам характер трафика является вредоносным.

**Порт 445 (SMB)** — используется в соединении с `win-cosmic-mind.monasticservice.org`. Это нетипично для SMB, который обычно направлен на внутренние файловые серверы. Такое поведение почти всегда свидетельствует об атаке.

## 5. Выводы

1. В дампе выявлен **подтверждённый фишинговый домен** `trallfasterinf.com`, связанный с внешним IP `137.184.114.20`. Антивирусные движки классифицируют его как угрозу.

2. Домен `ctldl.windowsupdate.com` формально является легитимным, но его появление требует проверки — возможно, злоумышленник использует его для обхода блокировок.

3. **Наиболее тревожная находка** — соединение с доменом `win-cosmic-mind.monasticservice.org` на порт 445 с внутреннего IP `10.9.23.23`. Это нетипичный сценарий: SMB-трафик не должен направляться на внешний ресурс с таким доменным именем. Такое поведение может свидетельствовать о попытке распространения вредоносного ПО по сети (например, через эксплуатацию уязвимостей SMB) или о наличии бэкдора.

4. Отсутствие детектов для двух последних доменов в VirusTotal не исключает их вредоносности, особенно в сочетании с аномальными портами.

---

## 6. Рекомендации

1. Заблокировать домен `trallfasterinf.com` и IP `137.184.114.20` на всех сетевых уровнях.
2. Заблокировать домен `win-cosmic-mind.monasticservice.org` и любой трафик на порт 445, исходящий от хоста `10.9.23.23` (если он не является легитимным файловым сервером).
3. Настроить мониторинг исходящего SMB-трафика (445/TCP) на внешние адреса.
4. Проверить хост `10.9.23.23` на наличие вредоносного ПО.
