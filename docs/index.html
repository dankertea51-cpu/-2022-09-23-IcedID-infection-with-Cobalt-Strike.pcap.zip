Почему SMB наружу — это критично

Главная находка разбора

Порт 445 обслуживает протокол SMB, который штатно работает только внутри периметра. Исходящее SMB-соединение на внешний домен нетипично и почти всегда указывает на попытку горизонтального перемещения, эксплуатацию уязвимостей SMB либо на канал бэкдора. Отсутствие детектов в VirusTotal у домена не снимает подозрений: свежие C2-домены попадают в базы с задержкой. 
# Быстрая проверка собственного дампа
tshark -r capture.pcap -Y 'tcp.dstport == 445 && !(ip.dst == 10.0.0.0/8) \
  && !(ip.dst == 192.168.0.0/16) && !(ip.dst == 172.16.0.0/12)' \
  -T fields -e ip.src -e ip.dst

Рекомендации

Приоритизированный план реагирования

  1. Заблокировать домен trallfasterinf.com и IP 137.184.114.20 на всех сетевых уровнях.
  2. Заблокировать win-cosmic-mind.monasticservice.org и исходящий 445/TCP от хоста 10.9.23.23.
  3. Изолировать и проверить хост 10.9.23.23 на наличие вредоносного ПО.
  4. Настроить постоянный мониторинг исходящего SMB-трафика на внешние адреса.
  5. Проверить частоту обращений к ctldl.windowsupdate.com на предмет маскировки трафика.
